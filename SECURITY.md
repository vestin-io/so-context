# Security Policy

## Reporting a vulnerability

Please do not open public GitHub issues for suspected security vulnerabilities.

Instead, report them privately to `info@vestin.io` with:

- A description of the issue
- Impact assessment
- Reproduction steps or proof of concept
- Any suggested mitigation if available

If GitHub private security advisories are enabled for this repository, you may
also use that channel. Otherwise, email `info@vestin.io` before any public
disclosure.

## Disclosure expectations

- We will aim to acknowledge receipt quickly.
- We may ask follow-up questions or request a reproduction.
- Please give us reasonable time to investigate and ship a fix before public
  disclosure.

## Scope

This policy covers vulnerabilities in the `so-context` codebase and its release
artifacts. It does not automatically extend to third-party dependencies or
external services unless the issue is specific to how `so-context` uses them.
